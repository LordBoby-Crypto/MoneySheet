# Pocket Money

A mobile-first offline-capable personal cash flow planner for iPhone and desktop. This public repository contains **application code only**. Never commit bank balances, paycheck amounts, personal bills, private backup files, or account credentials.

Once the static site is published on GitHub Pages, open it in Safari and use Share > Add to Home Screen. All budget entries stay in this browser's local storage; data is not synced across devices. Import the separately provided personal backup JSON file on each device and use Export Backup to move later changes.

To publish: Repository Settings > Pages > Deploy from a branch > main / (root) > Save.

Important: Projection numbers are estimates, not live bank data. Actual spending and deposits must be logged. Do not count a deposit already included in the starting bank balance twice.
